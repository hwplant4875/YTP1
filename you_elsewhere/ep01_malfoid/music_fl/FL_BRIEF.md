# Hedwig jazz trio: render in FL Studio (laptop)

Input: `hedwig_trio.mid` (88 BPM, 3/4, ~2 min). Tracks: 1 Piano, 2 Upright Bass, 3 Brush Drums (GM ch 10).
Generated by `hedwig_trio_midi.py` (edit notes there, not in FL, so the arrangement stays reproducible).

Goal: a warm, romantic late-night jazz piano trio that sounds like a real recording, NOT cheap General MIDI.
1. Open FL Studio (already installed on the laptop) and import the MIDI (File > Import > MIDI file, or open the .mid).
2. Instruments, best available on the laptop:
   - Piano: a good sampled acoustic grand (FL Keys / FLEX grand piano preset / any installed VST like Spitfire LABS Soft Piano). Soft, warm, felt-ish tone.
   - Bass: a sampled upright/acoustic bass (FLEX or any installed bass), round and soft.
   - Drums: brush kit if available (FPC/FLEX brushes); keep VERY quiet; if no brushes, use only a soft ride + hat, or mute drums.
3. Mix: piano centre-ish stereo, bass centre, drums low (-12 dB under piano). Gentle room/plate reverb (Fruity Reeverb 2 / Valhalla if installed), no harsh highs (cut a little above 6 kHz), no limiter pumping. Keep the original stereo image.

   Command-line render (once an .flp exists): `"<FL dir>\FL64.exe" /R /Ewav "<project>.flp"`. GUI export is fine too.
5. Commit the mp3 + .flp to `you_elsewhere/ep01_malfoid/music_fl/out/` on branch claude/project-thread-uxub9k and push. Report which instruments/plugins you used.
