# You, Elsewhere EP1: 30-minute suite v1 (`you_elsewhere_ep01_suite_v1.mp3`, 29:29, 256k)

Twelve tracks crossfaded (4 s), each matched to -20 LUFS first; the whole file sits at about -17 LUFS, peaks under -1.5 dBFS.
Made by script: `compose_suite.py` writes MIDI per instrument, renders it with sfizz_render, and mixes each track with ffmpeg
(v1 piano chain + FL "Chamber Warm" convolution send).
